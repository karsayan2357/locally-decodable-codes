\chapter{Private Information Retrieval}
\label{ch:pir}

Private Information Retrieval schemes were first introduced in the paper \cite{pir-sudan}. This chapter will consist of the PIR scheme described in \cite{improved-pir}.

\section{Introduction}

In a $k$-server Private Information Retrieval (PIR) scheme, a user wishes to retrieve the $i$-th bit $a_i$ of an $n$-bit database $\bfa = (a_1, \ldots, a_n) \in \{0,1\}^n$,
which is replicated among $k$ non-communicating servers, without revealing any
information about the index $i$ to any individual server.
The central goal in the study of PIR schemes is to minimize the \emph{communication cost}, defined as the worst-case total number of bits exchanged between the user and the servers over the course of the protocol.
The trivial solution, which works even with a single server, is to have the server transmit the entire database $\bfa$ to the user; this achieves correctness and perfect privacy, but at the high cost of $n$ bits of communication. A fundamental question is therefore: \emph{can we do better}?

Before moving forward let me define formally what a PIR scheme is:
\begin{definition}[PIR Scheme]

    A one-round $t$-server PIR protocol involves $t$ servers $S_1, \ldots, S_t$, each holding
the same $n$-bit database $\bfa = (a_1, \ldots, a_n) \in \{0,1\}^n$, such that
these servers do not communicate with each other, and there is a user $\calu$
who knows $n$ and wishes to retrieve some bit $a_i$ for $i \in [n]$, without revealing
the index $i$. The protocol consists of a randomized algorithm for the user and $t$
deterministic algorithms for the servers, satisfying the following:

\begin{enumerate}
    \item On input $i \in [n]$, the user $\calu$ samples a random string $\mathsf{rand}$,
    produces $t$ queries $q_1, \ldots, q_t$, and sends query $q_j$ to server $S_j$.

    \item Each server $S_j$ computes a response $r_j = S_j(\bfa, q_j)$ and sends
    it back to the user.

    \item The user, given $i$, $\mathsf{rand}$, and responses $r_1, \ldots, r_t$,
    reconstructs $a_i$.
\end{enumerate}

\noindent The protocol must satisfy the following two conditions:

\begin{itemize}
    \item \textbf{Correctness:} For any database $\bfa \in \{0,1\}^n$ and any
    index $i \in [n]$, the user outputs $a_i$ with probability $1$, where the
    probability is taken over the random string $\mathsf{rand}$.

    \item \textbf{Privacy:} Each server individually learns nothing about the queried
    index $i$. Formally, for any server $S_j$ and any two indices $i_1, i_2 \in [n]$,
    the distributions of $q_j(i_1, \mathsf{rand})$ and $q_j(i_2, \mathsf{rand})$ over
    the randomness $\mathsf{rand}$ are identical.
\end{itemize}
    
\end{definition}

For $1$-server PIR scheme, we can not do better than $n$ communication cost as if we have less than $n$ bits of communication, then there would be two indices for which we may have the same message from the server. In \cite{pir-sudan}, we have a $2$-server PIR scheme with $\O(n^{1/3})$ and $3$-server PIR scheme with $\O(n^{1/2})$ communication cost. Then in \cite{efr09}, we have a communication $2^{\tO(\sqrt{\log n})}$ for $3$-server PIR scheme.  


\section{A Basic PIR Scheme}\label{sec:basic-pir}

The following PIR Scheme will give us a $\O(n^{1/2})$ communication with $3$ servers. If $\bfa\in\bbf^n \equiv \bbf^{\binom{k}{2}}$ is our database and user wants $\bfa_{\tau}$, then it equivalent to construct a polynomial $F\in\bbf[x_1,\ldots,x_k]$ defined as:

\[
    F(x_1,\ldots, x_k) = \sum_{i,j} a_{ij}X_iX_j.
\]
For some re-design of the indexing set and have the user find a suitable $a_{ij}$ such that it equals $a_{\tau}$, by giving the evaluation of $F$ at $(0,\ldots,1,\ldots,1,\ldots,0)$, with $1$ only appearing in $i$ and $j$-th coordinates. 

We generalize this problem in the given PIR scheme and solve it via $3$-servers and $\O(n^{1/2})$ communication.

\subsection*{PIR Scheme}

Suppose for an $\bfx\in\bbf^k$, the user wants $F(\bfx)$ and the servers has the polynomial $F$. 

\begin{enumerate}
    \item Pick $\bfy\in\bbf^k$ uniformly at random. 
    \item Consider the curve $C(Z) = \bfx + Z\bfy$.
    \item Consider the restriction $A(Z) = F(C(Z)) = F(\bfx + Z\bfy)$ of $F$ on this curve, notice that $\deg A = 2$. 
    \item For $i\in[3]$, ask server $i$ to return $A(i)$ to the user.
    \item Interpolate $A$ using $A(1), A(2)$ and $A(3)$.
    \item Return $A(0)$.
\end{enumerate}

The correctness of the PIR scheme is easy to observe. And we send $k$-bit information to each server and receive $1$-bit information from each server. Thus in total the communication cost is $\O(k) = \O(n^{1/2})$ as $n = \binom{k}{2}$.

\section{PIR Scheme of \cite{improved-pir}}

The PIR scheme described in Section~\ref{sec:basic-pir} is the main idea behind all the PIR schemes that are to come. We pick a random curve in a space and restrict the polynomial(not exactly the same as in Section~\ref{sec:basic-pir}) to that curve and try to interpolate the polynomial, if the entire polynomial can not be interpolated(which will be the case), then we shall try to interpolate the value of the polynomial at $0$ only. 

PIR schemes using matching vectors were introduced in \cite{yek08-3ldc} and \cite{efr09}. A very detailed and well-written flow of improvement of the PIR schemes throughout the years can be found in \cite{improved-pir}. But we shall only see and explore the improvement done by the very paper. 

But before going to the actual explicit PIR scheme, we need to be familiar with some ideas required for the scheme to make sense and implement.

Suppose the database here is $\bfa\in\bbf^n$ and the user wants $a_{\tau}$. Also $(\bfu_1,\bfv_1),\ldots,(\bfu_n,\bfv_n)$ is an $S$-matching vector family in $\bbz_m^k$ for some positive integer $m$. Now the servers make the polynomial $F(\bfX)\in\bbf[X_1,\ldots,X_k]$ as follows:

\[
    F(\bfX) = \sum_{i = 1}^{n} a_i\bfX^{\bfu_i} = \sum_{i = 1}^{n}a_i X_1^{u_{i1}}\cdots X_k^{u_{ik}}.
\]

We shall deal with the restriction of this polynomial throughout the chapter. Also we choose the characteristic $p$ field $\bbf$ such that it contains all the $m$-th root of unity.

We first construct the random curve $C(Z)$ by first choosing $\bm{\beta}$ uniformly at random and considering $C(Z) = \bm{\beta}\hprod Z^{\bfv_{\tau}}$. Then consider the univariate polynomial $A(Z) = F(C(Z))$, but $\deg(A) = \O(k\cdot m^2)$. So to reduce it, we do $A_1(Z) = A(Z) \pmod{Z^m - 1}$. Observe that $A_1$ is of the form: 
\[
    A_1(Z) = a_{\tau}\bm{\beta}^{\bfu_{\tau}} + \sum_{\substack{s\in S \\ s \neq 0}} w_s Z^s.
\]

So to get $a_{\tau}$, it is enough to know $A_1(0)$. We shall try to interpolate $A_1$ at $0$ in the following sections. 

\subsection{Preliminaries}

We shall be doing the interpolation in the regime using \emph{$S$-mathcing vector families} and \emph{$S$-decoding polynomials}, or the SMVF+SSD framework. We have already seen SMVF before in Chapter~\ref{ch:mvc}, let us define what SSD is.

\begin{definition}[$S$-decoding Polynomials]
    Let $S \subseteq \mathbb{Z}_m$ be a set containing $0$. Let $\bbf$ be a field containing an element $\gamma_m$ which is a primitive $m$'th root of $1$. A polynomial $P(Z) \in \bbf[Z]$ is called an \textit{S-decoding polynomial} if the following conditions hold:
\begin{itemize}
    \item $\forall s \in S \setminus \{0\}: P(\gamma_m^s) = 0$
    \item $P(\gamma_m^0) = P(1) = 1$
\end{itemize}
\end{definition}

Now we can state the main theorem that is the result of \cite{improved-pir}, which improves the communication and server trade-off.

\begin{definition}[Canonical Set]
    Let $m\in\bbn$, we define \emph{canonical set} for $m$ to be:
    \[
        S = \{x\in\bbz_m : x^2 \equiv x\pmod m\}.    
    \] 
\end{definition}

The following is the main result that we shall prove in the coming sections.

\begin{blackbox}
    \begin{theorem}[\cite{improved-pir}]
        Let $m$ be a positive integer with $r$ distinct prime factors, and let $p$ be a prime not dividing $m$.
Suppose $\bbf$ is a field of characteristic $p$ such that, for $S^* \subseteq \mathbb{Z}_m$ being the canonical set for $m$, there is an $S^*$-decoding polynomial over $\bbf$ with sparsity $\leq t$.
Then there is a $t$-server PIR scheme with communication $\exp\left(\tO\left((\log n)^{\frac{1}{r+1}}\right)\right)$.
    \end{theorem}
\end{blackbox}

This is a direct improvement of the result of \cite{efr09}, which is:

\begin{blackbox}
    \begin{theorem}[\cite{efr09}]
        Let $m$ be a positive integer with $r$ distinct prime factors, and let $p$ be a prime not dividing $m$.
Suppose $\bbf$ is a field of characteristic $p$ such that, for $S^* \subseteq \mathbb{Z}_m$ being the canonical set for $m$, there is an $S^*$-decoding polynomial over $\bbf$ with sparsity $\leq t$.
Then there is a $t$-server PIR scheme with communication $\exp\left(\tO\left((\log n)^{\frac{1}{r}}\right)\right)$.
    \end{theorem}
\end{blackbox}

\subsection*{Hasse Derivatives}
    \begin{definition}[Hasse Derivatives]
        For a multivariate polynomial $F(\bfX) \in \bbf[\bfX]$ and a non-negative integer vector $\bfi = (i{(1)}, \ldots, i{(k)})$, we denote the \emph{$\bfi$-th Hasse derivative} of $F$ by $F^{(\bfi)}(X)$, and it is the coefficient of $\bfY^{\bfi}$ in the polynomial $F(\bfX + \bfY) \in \bbf[\bfX, \bfY]$. Therefore, we have,

\[F(\bfX + \bfY) = \sum_{\bfi} F^{(\bfi)}(\bfX)\, \bfY^{\bfi}.\]
    \end{definition}

We use the notation $F^{(<m)}(\bfa)$ to be the vector of all the evaluations of the $\bfi$-th Hasse derivative of $F$ at point $\bfa$ for all vectors $\bfi$ such that $\wt(\bfi) < m$. We note that Hasse derivatives are just a simple scaling of standard iterated derivatives whenever the order of derivative is smaller than the characteristic of the field. In particular, for the univariate polynomial $A(Z) = Z^s$, we have a simple formula for the Hasse derivative:

$$A^{(j)}(Z) = \binom{s}{j} Z^{s-j}.$$

Now the following facts about hasse derivatives are essential for interpolating $A_1()$ from its derivatives.

\begin{itemize}
    \item Let $A(Z) \in \mathbb{F}[Z]$ be a univariate polynomial, and let $b \in \mathbb{F}$. Then knowing $A(Z) \bmod (Z-b)^m$ is exactly equivalent to knowing $A^{(<m)}(b)$. Concretely, given $A^{(<m)}(b)$ we can construct the polynomial
    $$A^*(Z) = \sum_{i=0}^{m-1} A^{(i)}(b)(Z-b)^i,$$
    which is easily seen to be the remainder of $A(Z) \bmod (Z-b)^m$. This connection goes in the other direction too.

    \item \textbf{Chain rule:} Suppose $F(X_1, \ldots, X_k) \in \bbf[X_1, \ldots, X_k]$ is a multivariate polynomial and $C = (P_1(Z), \ldots, P_k(Z))$ is a tuple of univariate polynomials in the single variable $Z$. Denote their composition by the polynomial $A(Z) = F(C(Z))$. Then, the $i$-th Hasse derivative of $A$, $A^{(i)}$, can be expressed as a polynomial in $F^{(\bfj)}(C(Z))$ for $\wt(\bfj) \leq i$ and $P_t^{(j)}(Z)$ for $1 \leq t \leq k,\, j \leq i$.
\end{itemize}
